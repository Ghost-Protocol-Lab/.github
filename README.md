# Ghost Protocol Labs: organization profile

This is the special `.github` repository for the [Ghost Protocol Labs](https://github.com/Ghost-Protocol-Lab) GitHub organization.

| Path | What it does |
|---|---|
| `profile/README.md` | The README shown on the organization's public profile page. |
| `profile/assets/` | The ghost-themed SVG art used by that README (hero, section headers, divider, footer). |
| `scripts/make_assets.py` | Regenerates every SVG in `profile/assets/`. Python 3, standard library only. |
| `scripts/theme.py` | Shared palette, fonts and drawing helpers for the generator. |

Website: <https://ghost-protocol-lab.github.io/Ghost-Protocol-Lab/>

See [SETUP.md](SETUP.md) for how to publish and maintain it.
